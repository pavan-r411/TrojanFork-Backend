# TrojanPlate — Product Scope (Hackathon)

**Name:** TrojanPlate  
**Tagline:** Your goals. Your campus. Your plate.  
**Audience:** USC students  
**Platform:** Mobile-first web  
**Deadline:** Sunday, November 15, 2026, 11:00 AM PT

## One-sentence value

TrojanPlate recommends what USC students can actually eat today — from dining halls or nearby restaurants — based on their goals, diet, budget, and location, then updates the rest of the day when they swap a meal.

## Demo personas

1. **Maya** — vegetarian, high-protein preference, meal-plan user → USC Dining mode.  
2. **Jordan** — omnivore, $12 lunch budget, likes Mexican/Mediterranean → Off-Campus within 0.3 mi.

## In scope (P0)

- Profile onboarding (goal, diet, allergies, optional macros targets)  
- Two-mode home  
- Dated Village / EVK / Parkside snapshot  
- Curated off-campus dishes ≤0.3 mi  
- Day plan with ≤3 recommendations per period + explanations  
- Meal swap / replan  
- Public mobile demo UI  

## Out of scope for Sunday

- Live Places discovery  
- Walking Routes API  
- Multi-campus product  
- Medical advice / allergen guarantees  
- Hybrid campus+off-campus same-day planner
